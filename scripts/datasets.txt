# LIBSVM dataset registry for AGNS benchmarks.
#
# Format (whitespace-separated, one dataset per non-comment line):
#
#   name  url  family
#
# `name`    Local filename under ``$AGNS_DATA_DIR`` (default: ``data/``).
#           If the URL ends in ``.bz2`` the script auto-decompresses to
#           this name.  Use the *uncompressed* filename here.
# `url`     Fully-qualified upstream URL.
# `family`  One of ``binary`` or ``regression``.  Used by
#           ``download_data.sh`` to organise the local layout.
#
# Pinned datasets:
#   - mushrooms / a9a / w8a / phishing / ijcnn1     (binary, dense or
#     mildly sparse) -- driving logistic-regression and Soft-SVM
#     benchmarks.
#   - rcv1.binary                                    (binary, very sparse,
#     large feature count) -- inexact-Hessian benchmark.
#   - cadata / abalone                               (regression) --
#     ridge-regression benchmarks.
#
# Authoritative source: LIBSVM Tools dataset listing,
# https://www.csie.ntu.edu.tw/~cjlin/libsvmtools/datasets/
