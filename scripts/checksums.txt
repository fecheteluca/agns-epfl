# SHA-256 checksums for the LIBSVM datasets pinned in ``datasets.txt``.
#
# Format:  <name>  <sha256_hex>
#
# `name` matches the local filename column in datasets.txt (i.e. the
# uncompressed file).  Lines starting with ``#`` and blank lines are
# ignored.  Missing entries are tolerated by ``download_data.sh``:
# the script logs a warning and prints the freshly-computed digest so
# the operator can append it here for future verification.
#
# Why a separate file?  Pinning the checksums in version control means
# benchmark numbers can be reproduced bit-for-bit even if the upstream
# LIBSVM mirror swaps a file in place: any drift fails the SHA-256
# check loudly rather than silently changing the data.
#
# To populate or refresh entries, run:
#
#   AGNS_DATA_DIR=data bash scripts/download_data.sh
#   sha256sum data/<file>  # confirm matches the appended digest
#

# back to this file.)
